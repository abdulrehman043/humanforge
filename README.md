# HumanForge mobile texture pack

JPEG/PNG copies of the HumanForge WebP textures for expo-gl (its stb_image decoder can't read
WebP). Generated by `npm run build:mobile` in the main branch; the asset manifest points here via
`mobileTextures.baseUrl`. Kept on its own tag so each jsDelivr version stays under 50 MB.
